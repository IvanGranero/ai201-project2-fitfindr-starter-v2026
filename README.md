## What This Does

<!-- Three or four sentences: what a user asks for, and what they get back. -->

User asks for clothing piece that he/she is looking for for example 'a denim jacker under 50 bucks' and the agent will search for matches for it and get back with a match from the wardrove.

## Tool Inventory

<!-- Four lines per tool. This is worth 2 points and it's the single most
     common place students lose them.

     "Returns a list" earns NOTHING. The description has to say what is IN
     the list.

     The empty case isn't optional either — it's the thing your loop branches
     on, and if you don't decide it here you'll discover it as a crash in
     Milestone 5. -->

### `search_listings`
 
- **What it does:** Searches the thrift listings looking for items matching the user search and with optional filters by size and maximum price, then ranks matches by keyword relevance.
- **Inputs:**
- `description` (str): Keywords describing the item the user wants.
- `size` (str | None): Optional clothing or shoe size filter.
- `max_price` (float | None): Optional maximum acceptable price.
- **Returns:** `list[dict]` containing matching listing records sorted by relevance. Each listing dictionary includes fields such as `id`, `title`, `description`, `category`, `size`, `price`, `brand`, `colors`, and `platform`.
- **When it has nothing:** Returns an empty list `[]` when no listings match the search criteria.
 
### `suggest_outfit`
 
- **What it does:** Uses the selected thrift item and the user's wardrobe to generate outfit recommendations or styling advice.
- **Inputs:**
- `new_item` (dict): Listing dictionary representing the item being considered.
- `wardrobe` (dict): Wardrobe data containing an `items` list of clothing already owned by the user.
- **Returns:** A non-empty string containing one or more outfit suggestions, either referencing wardrobe items or providing general styling recommendations.
- **When it has nothing:** If `wardrobe["items"]` is empty, returns a string with general styling advice for the item instead of outfit combinations.
 
### `create_fit_card`
 
- **What it does:** Generates a short social-media-style caption describing the thrift find and the suggested outfit.
- **Inputs:**
- `outfit` (str): Outfit suggestion text generated by `suggest_outfit`.
- `new_item` (dict): Listing dictionary for the thrifted item.
- **Returns:** A 2–4 sentence caption mentioning the item, its price, its platform, and the overall style or vibe.
- **When it has nothing:** If `outfit` is empty or contains only whitespace, returns a descriptive message explaining that no outfit suggestion was available rather than raising an error.
